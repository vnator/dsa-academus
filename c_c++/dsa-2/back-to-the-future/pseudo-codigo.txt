ALGORITMO: Min-Cost Max-Flow (Successive Shortest Path)
====================================================

ESTRUTURAS DE DADOS:
-------------------

ESTRUTURA Aresta:
    destino: inteiro
    capacidade: inteiro  
    custo: inteiro
    fluxo: inteiro
    indice_reversa: inteiro

VARIAVEIS GLOBAIS:
    grafo[MAX_N]: lista de Arestas
    distancia[MAX_N]: inteiro (inicialmente INFINITO)
    pai_no[MAX_N]: inteiro
    pai_aresta[MAX_N]: inteiro
    em_fila[MAX_N]: booleano

FUNCOES AUXILIARES:
------------------

FUNCAO AdicionarAresta(u, v, capacidade, custo):
    INICIO
        // Aresta direta
        aresta_direta = {v, capacidade, custo, 0, tamanho(grafo[v])}
        grafo[u].adicionar(aresta_direta)
        
        // Aresta residual (reversa com custo negativo)
        aresta_reversa = {u, 0, -custo, 0, tamanho(grafo[u])-1}
        grafo[v].adicionar(aresta_reversa)
    FIM

FUNCAO SPFA(origem, destino, N):
    // Shortest Path Faster Algorithm (lida com custos negativos)
    INICIO
        PARA i = 1 ATÉ N FAÇA
            distancia[i] = INFINITO
            em_fila[i] = FALSO
        FIM PARA
        
        distancia[origem] = 0
        fila = nova_fila()
        fila.adicionar(origem)
        em_fila[origem] = VERDADEIRO
        
        ENQUANTO fila NÃO vazia FAÇA
            u = fila.remover_primeiro()
            em_fila[u] = FALSO
            
            PARA CADA aresta EM grafo[u] FAÇA
                v = aresta.destino
                capacidade_residual = aresta.capacidade - aresta.fluxo
                
                SE capacidade_residual > 0 E 
                   distancia[v] > distancia[u] + aresta.custo ENTÃO
                    distancia[v] = distancia[u] + aresta.custo
                    pai_no[v] = u
                    pai_aresta[v] = indice_da_aresta
                    
                    SE NÃO em_fila[v] ENTÃO
                        fila.adicionar(v)
                        em_fila[v] = VERDADEIRO
                    FIM SE
                FIM SE
            FIM PARA
        FIM ENQUANTO
        
        RETORNAR (distancia[destino] != INFINITO)
    FIM

ALGORITMO PRINCIPAL:
===================

FUNCAO ResolverBackToTheFuture():
    INICIO
        instancia = 1
        
        ENQUANTO LER(N, M) E (N != 0 OU M != 0) FAÇA
            // Limpar estruturas
            PARA i = 1 ATÉ N FAÇA
                grafo[i].limpar()
            FIM PARA
            
            // Ler rotas
            PARA i = 1 ATÉ M FAÇA
                LER(A, B, C)
                AdicionarAresta(A, B, K, C)  // Bidirecional
                AdicionarAresta(B, A, K, C)
            FIM PARA
            
            LER(D, K)  // D = amigos, K = assentos por voo
            
            // Aplicar Min-Cost Max-Flow
            custo_total = 0
            amigos_transportados = 0
            possivel = VERDADEIRO
            
            ENQUANTO amigos_transportados < D FAÇA
                SE NÃO SPFA(1, N, N) ENTÃO
                    possivel = FALSO
                    PARAR
                FIM SE
                
                // Encontrar gargalo do caminho
                fluxo_maximo_caminho = INFINITO
                atual = N
                ENQUANTO atual != 1 FAÇA
                    anterior = pai_no[atual]
                    indice = pai_aresta[atual]
                    aresta = grafo[anterior][indice]
                    capacidade_livre = aresta.capacidade - aresta.fluxo
                    fluxo_maximo_caminho = MIN(fluxo_maximo_caminho, capacidade_livre)
                    atual = anterior
                FIM ENQUANTO
                
                // Não enviar mais amigos do que necessário
                fluxo_enviar = MIN(fluxo_maximo_caminho, D - amigos_transportados)
                
                // Atualizar fluxos nas arestas do caminho
                atual = N
                ENQUANTO atual != 1 FAÇA
                    anterior = pai_no[atual]
                    indice = pai_aresta[atual]
                    
                    // Atualizar aresta direta
                    grafo[anterior][indice].fluxo += fluxo_enviar
                    
                    // Atualizar aresta reversa
                    indice_rev = grafo[anterior][indice].indice_reversa
                    grafo[atual][indice_rev].fluxo -= fluxo_enviar
                    
                    // Acumular custo
                    custo_total += fluxo_enviar * grafo[anterior][indice].custo
                    atual = anterior
                FIM ENQUANTO
                
                amigos_transportados += fluxo_enviar
            FIM ENQUANTO
            
            // Imprimir resultado
            ESCREVER("Instancia ", instancia)
            SE possivel ENTÃO
                ESCREVER(custo_total)
            SENÃO
                ESCREVER("impossivel")
            FIM SE
            ESCREVER(nova_linha)
            
            instancia += 1
        FIM ENQUANTO
    FIM

EXEMPLO DE EXECUÇÃO (Instância 1):
=================================

ENTRADA:
4 5
1 4 1    // Rota direta: cidade 1 → cidade 4, custo 1
1 3 3    // Rota: cidade 1 → cidade 3, custo 3
3 4 4    // Rota: cidade 3 → cidade 4, custo 4  
1 2 2    // Rota: cidade 1 → cidade 2, custo 2
2 4 5    // Rota: cidade 2 → cidade 4, custo 5
20 10    // 20 amigos, 10 assentos por voo

EXECUÇÃO:
1ª Iteração:
  - SPFA encontra caminho mais barato: 1 → 4 (custo 1)
  - Fluxo enviado: min(10 assentos, 20 amigos) = 10 amigos
  - Custo: 10 × 1 = 10
  - Amigos restantes: 10

2ª Iteração:  
  - Rota direta 1→4 saturada (capacidade residual = 0)
  - SPFA encontra: 1 → 2 → 4 (custo 2+5 = 7) OU 1 → 3 → 4 (custo 3+4 = 7)
  - Fluxo enviado: min(10 assentos, 10 amigos) = 10 amigos  
  - Custo: 10 × 7 = 70
  - Amigos restantes: 0

RESULTADO FINAL:
Custo total = 10 + 70 = 80

SAÍDA:
Instancia 1
80

INVARIANTES DO ALGORITMO:
========================

1. CONSERVAÇÃO DE FLUXO:
   - Para todo vértice v (exceto origem e destino):
     Σ(fluxo_entrada) = Σ(fluxo_saída)

2. RESTRIÇÃO DE CAPACIDADE:
   - Para toda aresta (u,v): 0 ≤ fluxo(u,v) ≤ capacidade(u,v)

3. OTIMALIDADE:
   - O algoritmo sempre escolhe o caminho de menor custo disponível
   - Arestas reversas permitem "cancelar" fluxo subótimo em iterações futuras

4. TERMINAÇÃO:
   - O algoritmo termina quando:
     a) Todos os D amigos foram transportados (sucesso), ou  
     b) Não existe caminho viável no grafo residual (impossível)
