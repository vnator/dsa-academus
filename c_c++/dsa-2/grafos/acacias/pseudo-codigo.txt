ALGORITMO: Problema das Acácias - Árvore Geradora Mínima (Kruskal)
=======================================================================

ESTRUTURAS DE DADOS:
-------------------

ESTRUTURA Aresta:
    ATRIBUTOS:
        origem: inteiro
        destino: inteiro  
        peso: inteiro
    
    MÉTODO compararPorPeso(outra):
        RETORNAR (peso < outra.peso)

CLASSE UnionFind:
    ATRIBUTOS PRIVADOS:
        pai[]: array de inteiros (representa pai de cada elemento)
        rank[]: array de inteiros (altura da árvore)
    
    MÉTODO PÚBLICO construtor(n):
        INÍCIO
            PARA i DE 0 ATÉ n-1 FAÇA
                pai[i] ← i        // Cada elemento é pai de si mesmo
                rank[i] ← 0       // Altura inicial é 0
            FIM PARA
        FIM
    
    MÉTODO PÚBLICO find(x):
        // Encontra representante com compressão de caminho
        INÍCIO
            SE pai[x] ≠ x ENTÃO
                pai[x] ← find(pai[x])    // Compressão de caminho
            FIM SE
            RETORNAR pai[x]
        FIM
    
    MÉTODO PÚBLICO unite(x, y):
        // Une dois conjuntos usando union by rank
        INÍCIO
            rootX ← find(x)
            rootY ← find(y)
            
            SE rootX = rootY ENTÃO
                RETORNAR FALSO    // Já estão no mesmo conjunto
            FIM SE
            
            // Union by rank
            SE rank[rootX] < rank[rootY] ENTÃO
                pai[rootX] ← rootY
            SENÃO SE rank[rootX] > rank[rootY] ENTÃO
                pai[rootY] ← rootX
            SENÃO
                pai[rootY] ← rootX
                rank[rootX] ← rank[rootX] + 1
            FIM SE
            
            RETORNAR VERDADEIRO
        FIM

CLASSE ArvoreGeradoraMinima:
    ATRIBUTOS PRIVADOS:
        numVertices: inteiro
        arestas[]: array de Aresta
    
    MÉTODO PÚBLICO construtor(v):
        INÍCIO
            numVertices ← v
            arestas ← array vazio
        FIM
    
    MÉTODO PÚBLICO adicionarAresta(origem, destino, peso):
        INÍCIO
            aresta ← nova Aresta(origem, destino, peso)
            arestas.adicionar(aresta)
        FIM
    
    MÉTODO PÚBLICO kruskal():
        INÍCIO
            // 1. Ordenar arestas por peso crescente
            arestas.ordenarPorPeso()
            
            // 2. Inicializar estruturas
            uf ← novo UnionFind(numVertices)
            mst ← array vazio
            custoTotal ← 0
            
            // 3. Processar arestas em ordem
            PARA CADA aresta EM arestas FAÇA
                SE uf.unite(aresta.origem, aresta.destino) ENTÃO
                    mst.adicionar(aresta)
                    custoTotal ← custoTotal + aresta.peso
                    
                    // MST completa quando tem V-1 arestas
                    SE mst.tamanho() = numVertices - 1 ENTÃO
                        PARAR
                    FIM SE
                FIM SE
            FIM PARA
            
            RETORNAR (custoTotal, mst)
        FIM
    
    MÉTODO PÚBLICO ehConexo():
        INÍCIO
            SE arestas.vazio() ENTÃO
                RETORNAR (numVertices ≤ 1)
            FIM SE
            
            resultado ← kruskal()
            mst ← resultado.segundoElemento
            RETORNAR (mst.tamanho() = numVertices - 1)
        FIM

ALGORITMO PRINCIPAL:
===================
INÍCIO
    LER n    // Número de casos de teste
    
    PARA caso DE 1 ATÉ n FAÇA
        LER v, e    // Número de vértices e arestas
        
        // Criar grafo
        grafo ← novo ArvoreGeradoraMinima(v)
        
        // Ler arestas
        PARA i DE 1 ATÉ e FAÇA
            LER origem, destino, peso
            grafo.adicionarAresta(origem, destino, peso)
        FIM PARA
        
        // Verificar conectividade
        SE NÃO grafo.ehConexo() ENTÃO
            ESCREVER "Case #", caso, ": Impossivel conectar todas as acacias"
            CONTINUAR
        FIM SE
        
        // Encontrar MST
        resultado ← grafo.kruskal()
        custoMinimo ← resultado.primeiroElemento
        mst ← resultado.segundoElemento
        
        // Imprimir resultado
        ESCREVER "Case #", caso, ":"
        ESCREVER "Custo minimo para conectar as acacias: ", custoMinimo
        ESCREVER "Arestas da arvore geradora minima:"
        
        PARA CADA aresta EM mst FAÇA
            ESCREVER aresta.origem, " -- ", aresta.destino, 
                     " (peso: ", aresta.peso, ")"
        FIM PARA
        
        ESCREVER nova_linha
    FIM PARA
FIM

DETALHAMENTO DO ALGORITMO DE KRUSKAL:
====================================

OBJETIVO: Encontrar árvore geradora de custo mínimo

PRINCÍPIO: Algoritmo guloso que escolhe sempre a aresta de menor peso
          que não cria ciclo

PASSOS:
1. ORDENAÇÃO: Ordenar todas as arestas por peso crescente
2. INICIALIZAÇÃO: Cada vértice forma seu próprio conjunto
3. PROCESSAMENTO: Para cada aresta em ordem:
   a. Se conecta vértices de conjuntos diferentes:
      - Adicionar aresta à MST
      - Unir os conjuntos
   b. Senão: descartar (criaria ciclo)
4. PARADA: Quando MST tem V-1 arestas

EXEMPLO PASSO A PASSO:
=====================

ENTRADA:
Vértices: {0, 1, 2, 3}
Arestas: (0-1,10), (0-2,6), (0-3,5), (1-2,15), (1-3,4), (2-3,8)

PASSO 1 - ORDENAÇÃO:
(1-3,4), (0-3,5), (0-2,6), (2-3,8), (0-1,10), (1-2,15)

PASSO 2 - INICIALIZAÇÃO:
Conjuntos: {0}, {1}, {2}, {3}
MST: vazia
Custo: 0

PASSO 3 - PROCESSAMENTO:

Iteração 1: Aresta (1-3, peso 4)
- find(1) = 1, find(3) = 3 → conjuntos diferentes
- Unite(1, 3) → sucesso
- MST: {(1-3,4)}, Custo: 4
- Conjuntos: {0}, {1,3}, {2}

Iteração 2: Aresta (0-3, peso 5)
- find(0) = 0, find(3) = 1 → conjuntos diferentes  
- Unite(0, 3) → sucesso
- MST: {(1-3,4), (0-3,5)}, Custo: 9
- Conjuntos: {0,1,3}, {2}

Iteração 3: Aresta (0-2, peso 6)
- find(0) = 1, find(2) = 2 → conjuntos diferentes
- Unite(0, 2) → sucesso
- MST: {(1-3,4), (0-3,5), (0-2,6)}, Custo: 15
- Conjuntos: {0,1,2,3}
- MST completa (3 arestas para 4 vértices)

RESULTADO FINAL:
Custo mínimo: 15
Arestas: (1-3,4), (0-3,5), (0-2,6)

INVARIANTES DO ALGORITMO:
========================

1. INVARIANTE DA ORDENAÇÃO:
   - Arestas são sempre processadas em ordem crescente de peso
   - Garante propriedade gulosa ótima

2. INVARIANTE DO UNION-FIND:
   - Conjuntos disjuntos representam componentes conexos
   - Union só ocorre entre conjuntos diferentes

3. INVARIANTE DA MST:
   - A cada passo, temos uma floresta de árvores geradoras mínimas
   - MST final é união dessas árvores

4. INVARIANTE DE CORREÇÃO:
   - Algoritmo termina com exatamente V-1 arestas (se grafo for conexo)
   - Custo é mínimo possível para conectar todos os vértices

COMPLEXIDADE DETALHADA:
======================

TEMPO:
1. Ordenação das arestas: O(E log E)
2. Inicialização Union-Find: O(V)
3. Processamento das arestas: O(E × α(V))
   - α(V) é função inversa de Ackermann ≈ constante
4. TOTAL: O(E log E + V + E × α(V)) = O(E log E)

ESPAÇO:
1. Armazenamento das arestas: O(E)
2. Union-Find (pai + rank): O(V)
3. MST resultante: O(V)
4. TOTAL: O(E + V)

CASOS ESPECIAIS:
===============

1. GRAFO DESCONEXO:
   - MST terá menos que V-1 arestas
   - Impossível conectar todos os vértices

2. GRAFO COMPLETO:
   - E = V(V-1)/2 arestas
   - Kruskal escolhe V-1 menores

3. EMPATES DE PESO:
   - Múltiplas MSTs possíveis
   - Algoritmo encontra uma delas

4. GRAFO JÁ É ÁRVORE:
   - MST = próprio grafo
   - Algoritmo confirma otimalidade
