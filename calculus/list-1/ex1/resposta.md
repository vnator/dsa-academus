# Resposta pra questao descritiva

## Média de iterações:

Falsa Posição: 5 iterações (2, 8, 5)
Bissecção: 11 iterações (10, 9, 15)

Justificativa:  Falsa posição aproxima a raiz usando uma reta entre os pontos do intervalo, enquanto bissecção só divide no meio. Linear converge mais rápido que binaria nesse cenario.
